# 数据说明

本目录存放 InvoiceOps 分类模型的训练、开发、测试数据，以及一份用于批量分类的工单文件。

**数据来源：** 网上开源获取，仅供参考。

## 文件

| 文件 | 用途 | 行数 |
|---|---|---|
| `invoiceops_train.csv` | 训练集，用于拟合模型 | 4,372 |
| `invoiceops_dev.csv` | 开发集，用于选择模型检查点和各标签阈值 | 781 |
| `invoiceops_test.csv` | 测试集，只在最终评估时使用一次 | 847 |
| `invoiceops_online.csv` | 批量分类输入文件，可直接在工作台“CSV 批量”页面上传（见下文“批量分类文件”） | 500 |

所有文件都是 UTF-8 编码的 CSV。前三个文件带标签，共 6,000 条中文、英文和中英混合的发票与付款工单文本；以下“字段”“标签”“分布”“数据校验”各节都只针对这三个文件。

## 字段

| 字段 | 说明 |
|---|---|
| `request_id` | 工单编号，例如 `ticket-0001` |
| `source` | 来源渠道：`email`（邮件）或 `portal`（供应商门户） |
| `text` | 工单正文，是训练时唯一使用的特征 |
| `language` | 语言：`zh`（中文）、`en`（英文）、`mixed`（中英混合） |
| `labels` | 标签，多个标签用 `\|` 分隔，例如 `PRICE_VARIANCE\|TAX_CURRENCY_AMOUNT` |
| `template_group`、`translation_group`、`supplier_context_group`、`leakage_group` | 分组字段（模板、翻译、供应商场景、泄漏检查）。同一组的工单只能出现在同一个切分中，避免训练集和测试集内容相近 |
| `taxonomy_version` | 标签体系版本，当前为 `invoiceops-v1` |
| `review_status` | 标注复核状态，当前均为 `pending_review` |
| `redaction_types` | 文本脱敏的类型列表 |
| `redaction_count` | 文本脱敏的次数 |

## 标签

标签定义和顺序以 `configs/taxonomy.json` 为准。每条工单有 1 或 2 个标签。

| 标签 | 含义 | 训练集 | 开发集 | 测试集 |
|---|---|---|---|---|
| `DUPLICATE_INVOICE` | 重复开票或重复付款 | 660 | 124 | 146 |
| `MISSING_PO_OR_RECEIPT` | 缺少采购订单或收货凭证 | 745 | 91 | 94 |
| `OTHER_REVIEW` | 其他需要人工判断的问题 | 559 | 129 | 62 |
| `PAYMENT_STATUS` | 付款进度查询 | 513 | 128 | 109 |
| `PRICE_VARIANCE` | 发票单价与采购订单不符 | 617 | 127 | 186 |
| `QUANTITY_RECEIPT_VARIANCE` | 开票数量与收货数量不符 | 714 | 126 | 90 |
| `SUPPLIER_MASTER_CHANGE` | 供应商主数据（如收款银行账户）变更 | 635 | 115 | 150 |
| `TAX_CURRENCY_AMOUNT` | 税额、币种或金额合计有误 | 685 | 104 | 141 |

## 数据校验

在项目根目录运行：

```powershell
uv run python -m invoiceops.data --train data/invoiceops_train.csv --dev data/invoiceops_dev.csv --test data/invoiceops_test.csv --manifest ml/data_manifest.json
```

校验器（`src/invoiceops/data/contract.py`）会检查：

- 必需字段是否齐全；
- 标签是否属于标签体系、是否有空值；
- 训练、开发、测试三个切分之间是否有重复文本或分组泄漏。

校验通过后，每个文件的行数、标签分布、语言分布和 SHA-256 会写入 `--manifest` 指定的文件。训练和评估命令同样会先做这项校验。

## 批量分类文件

`invoiceops_online.csv` 是不带标签的工单文件，格式与系统的 CSV 批量上传要求一致，用于体验和检查批量分类流程。

| 字段 | 说明 |
|---|---|
| `text` | 工单正文，长度 25–205 字符 |
| `external_id` | 外部编号，例如 `TKT-20251111-143`、`CS-20260401-6722`，前缀有 `TKT`、`CS`、`RQ`、`INC`、`AP` 五种 |

- 共 500 行，编号和正文都没有重复，内容包括中文、英文和中英混合的工单。
- 与训练、开发、测试集没有重复文本，不参与模型训练和评估。
- 满足上传限制（不超过 10 MiB、10,000 行、单行 10,000 字符），用系统的 CSV 解析器检查 500 行全部有效。

使用方法：登录工作台，进入“CSV 批量”页面，上传该文件。后台逐行分类完成后，可以下载结果；需要复核的行会进入“待复核工单”。

## 使用约定

- 训练只使用训练集；检查点和阈值只用开发集选择。
- 测试集只用于最终评估，每个模型版本只评估一次，不能根据测试结果调参。
- 修改数据后，必须重新校验并训练新的模型版本。
